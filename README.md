# Reem's Games

A home for Reem's browser games.

## Simsim's little shed

A first-person 3D pigeon simulation. Be Simsim: explore the shed, fly through the pigeon trap, perch, eat seeds, and meet the flock.

Open `index.html` for the game menu, or download the repository and open `simsims-little-shed/index.html` in Chrome or Edge.

See [the game's README](simsims-little-shed/README.md) for controls and details.
